The goal of this project is to implement and train a Generative Adversarial Network (GAN) capable of generating images of handwritten letters using the EMNIST Letters dataset. Depending on the target grade, you will extend the basic GAN to support conditional generation and generation of previously unseen letters from a single example.

Grade 3.0 at most - Basic GAN
Grade 4.0 at most - Allow the user to specify a letter and generate images of that letter.
Grade 5.0 at most - Extend your solution to generate images of a letter that was not included in the GAN's training data, given only one example of that letter at generation time.
The project shall be done in pairs. When submitting, please provide the student IDs of the whole group. Only one person from a group should send the submission.
If submitting a Jupyter notebook, please include some comments and text describing your concept and the whole process of developing it. Also, show your trials and errors. If submitting code, please attach a report with the same description.
